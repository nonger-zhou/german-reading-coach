# 阅读页高亮、重叠与选区 — 技术说明与将来用户手册素材

本文档整理当前实现下的行为与限制，供产品说明、FAQ 与将来用户手册摘编。实现以代码为准：`src/lib/articleReadingModel.ts`（`buildRunsFromReadingItems` 优先级）、`src/components/InteractiveArticleReader.tsx`（正文渲染与选区浮层）。

## 1. 正文里「一块字」只会有一种高亮色

左侧正文按字符栅格合并高亮：同一位置**不会**同时叠两种颜色（不会出现「一块区域双色渐变」）。

重叠时按**优先级**决定显示哪一种（数值越大越优先）：

| 类型           | 说明           | 相对优先级（越高越覆盖对方） |
|----------------|----------------|------------------------------|
| 已掌握词汇锚点 | 默认几乎不显色 | 最低                         |
| 系统 / AI 语法 | 蓝色系         | 低于 AI 词汇                 |
| 系统 / AI 词汇 | 绿色系         | 高于 AI 语法                 |
| 用户语法       | 紫色系         | 低于用户                     |
| 用户           | 琥珀色系       | 最高                         |

因此：

- **先添加某个词，再添加包含该词的整句为语法**：两条学习记录都可以存在；但与词重叠的那几个字会显示**词汇**色，句子其余部分仍显示**语法**色。
- **先标语法，再在语法句子里标生词**：词汇记录同样可以添加；视觉上重叠段以**词汇**侧优先（若为用户词与用户语法重叠）。

## 2. 已掌握词汇在正文中的显示

- **默认**：已掌握词在正文中**不常驻**绿色 / 琥珀色背景高亮，减少阅读干扰。
- **按需定位**：从右侧「已掌握词汇」折叠区、词汇卡片中的本篇出现位置，或总词库来源链接进入时，仍可滚动到原文并**短暂闪烁**定位。
- 已掌握词锚点优先级设为最低，避免挡住仍需显示的语法或其它学习中高亮。

## 3. 在「语法高亮」内部继续添加词汇（当前限制与方向）

### 3.1 现状（简要）

- **手机 / 桌面**：课文语法（蓝）与用户语法（紫）在正文中使用 **`span role="button"`**，样式允许 **`user-select: text`**，且触摸时**不在 `pointerdown` 上 `preventDefault`**，以便在片段内拖选子串并用选区浮层「加入词库」。
- **轻点打开语法**：若当前存在**非空**文本选区，点击语法片段**不会**打开语法详情（避免拖选后误触）；无选区时轻点仍打开语法说明。
- **词汇高亮**（绿 / 琥珀）仍为 **`button`** + 触摸防护，优先保证点按打开词汇详情、减少 iOS 系统菜单干扰。
- **底部详情抽屉（手机）**：全屏变暗层须 **`pointer-events: none`**，避免挡住课文滚动与选词；打开后自动将对应高亮滚到抽屉上方留白；抽屉高度有上限（如 **`min(360px, 50dvh)`**）并保留底部安全区。

### 3.2 产品方向（未实现或部分未实现时可写进手册）

- **桌面**：若出现「单击打开语法」与「拖选」偶发冲突，可继续细化（例如更严格区分短按与拖选）。
- **手机**：若个别站点或 WebView 中选词仍不理想，可在语法详情中增加**「从本句挑选词汇」**等兜底入口。

具体以迭代后的 PRD 与版本说明为准。

## 4. 与 PRD「重叠规则」的关系

PRD §8.0 原则：**用户手动词汇**与**系统推荐**重叠时，原文样式优先用户侧。  
本文档补充的是：**用户 vs 用户语法**、以及 **AI 词汇 vs AI 语法** 等同为「单字符单一赢家」时的优先级与视觉效果。

## 5. Cursor / 自动化执行「Run」相关（给维护者）

本仓库的自动化助手在沙箱中执行命令时，是否每次都需要你点 **Run**，由 **Cursor 客户端安全策略**决定，无法在仓库代码里替你「永久授权」。

常见做法：

- 在弹出运行确认时，选择 **始终允许 / Allowlist / 信任此工作区** 等选项（文案因 Cursor 版本而异）。
- 在 Cursor **设置**中查看与 **Terminal / Agent / Sandbox / 命令批准** 相关的选项（名称随版本变化）。

若你希望少点确认，以你本机 Cursor 当前版本的官方说明为准。
